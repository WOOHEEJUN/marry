> 컨셉: 긴급속보(경찰 검거) + 교정본부(수감)
> 파티: 2026-08-08 ~ 09 · 결혼식: 2026-11-10

## 게임 구성

| # | 게임 | 사이트 표기 | 규칙 |
|---|---|---|---|
| 1 | 범인찾기 | 1차 집행 · 용의자 대질신문 | 3라운드 중 1회 이상 벌칙 음식 먹은 사람 적중 시 성공 |
| 2 | 이구이성 | 2차 집행 · 다중 음성 감청 | 5문제 중 3문제 이상 정답. 문제당 최대 3회 청취 |
| B | 천생연분 | 긴급 · 배우자 진술 대조 심사 | 신부 답변 맞히면 실패한 집행에 기회 1회 부활 |

게임 추가는 `config.json` 의 `games[]` 에 항목을 넣고 타입별 화면 컴포넌트를 등록하면 된다.

## 로컬 실행

```bash
npm install
npm run dev
```

- 웹 `http://localhost:5173` · API/WS `http://localhost:8000`
- 같은 와이파이의 폰에서 `http://<노트북IP>:5173` 으로 접속 가능
- **인터넷이 끊긴 현장에서는 이 모드로 진행하면 된다** (서버 불필요)

프로덕션과 동일하게 돌려보려면:

```bash
npm run preview
```

## 배포

```bash
npm run deploy
```

로컬 빌드 → `scp` 전송 → `systemctl restart marry`. 약 20~30초.

- 서버의 `config.json` 은 **덮어쓰지 않는다** (당일 `/admin` 수정분 보존)
- 서버 스펙이 낮아 빌드는 반드시 로컬에서 수행

## 구조

```
server/
  index.mjs     Fastify + WebSocket + 정적 파일 서빙
  state.mjs     게임 상태 리듀서 / 공개·컨트롤러 뷰 분리
src/
  Tv.tsx        TV 화면 (phase 별 라우팅)
  Spectator.tsx 폰 관전 요약
  Controller.tsx 진행자 컨트롤러
  Admin.tsx     설정 편집
  fx.tsx        연출 컴포넌트 (지폐비/도장/경광등/폴리스테이프…)
  sound.ts      Web Audio 합성 사운드 (오디오 파일 0개)
  screens/      화면별 컴포넌트
config.json     모든 설정 (금액·인원·단어·질문)
```

### 정답 노출 방지

서버가 상태를 **두 가지로 투영**한다.

- `publicView` — TV·폰용. 이구이성 단어는 **글자 수만**, 천생연분 답변은 `null`
- `controlView` — 컨트롤러용. 정답 포함

정답은 공개 시점 전까지 클라이언트로 아예 전송되지 않는다.

## 현장 대응

1. **어드민** (`/admin`) — 금액·인원·단어·질문 수정. 배포 불필요
2. **컨트롤러 즉흥 대응** — 보석금 수동 가감, 직전 판정 되돌리기, 라운드 추가/건너뛰기, 화면 강제 전환, 연출 수동 재생
3. **`npm run deploy`** — 코드를 진짜 고쳐야 할 때 (20~30초)
4. **`npm run dev`** — 인터넷이 죽었을 때. 노트북이 서버가 된다
