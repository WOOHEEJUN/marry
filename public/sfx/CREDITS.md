# 효과음 출처

이 폴더의 음원은 모두 자유 라이선스입니다.

## Kenney (CC0 — 퍼블릭 도메인, 출처 표기 의무 없음)

<https://kenney.nl> 의 오디오 팩에서 가져왔습니다.

| 접두어 | 원본 팩 |
|---|---|
| `jingle-` | Music Jingles |
| `wood-`, `metal-`, `glass-`, `bell-` | Impact Sounds |
| `error-`, `confirm-`, `question-`, `click-`, `select-`, `tick-`, `switch-`, `bong-`, `drop-`, `up-`, `down-` | Interface Sounds |
| `coins-`, `door-` | RPG Audio |
| `chip-` | Casino Audio |

## 직접 넣기

마음에 드는 효과음이 있으면 이 폴더에 `.ogg` / `.mp3` / `.wav` 로 넣고
`npm run deploy` 한 뒤 `/admin` 의 효과음 카드에서 골라 쓰면 됩니다.
